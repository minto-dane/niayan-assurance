# ADR-0002: 三リポジトリと単一の状態所有者

状態: superseded（構成数について[ADR-0021](ADR-0021.ja.md)で置換。状態所有者を一つにする原則は維持）。日付: 2026-09-06。対象: recovery-engineering source edition。

## 背景

このシステムは既存ディストリビューションの資産と複数の特権/外部状態を扱うため、単なる関数成功とシステム全体の正常性を混同できません。
この決定は「三リポジトリと単一の状態所有者」について、故障中の推測を減らし、責任と回復条件を明確にするためのものです。

## 決定

pkgcore、statecore、assuranceを維持し、同じ状態を二つの管理器の正本にしない。

## 代替案

全てを一つの巨大daemonで管理する案は特権とレビュー範囲を増やす。

## 影響

固定共有profileとcross-repo試験が必要になる。
可用性と安全性の両方への影響をレビューし、停止が必要な範囲と正常に継続できる業務を分けます。
既存の未適格な観測やコールバックを、この決定だけで適格化しません。

## 検証と残る条件

要求との関係はrequirements.jsonが正本です。コード、正/否定試験、障害注入、必要な証明/実機接続を同じsubjectで追跡します。
この配布時点でAda実行・GNATprove・実クラスタの検証は未実施です。独立レビュー担当者と承認結果も未登録です。
