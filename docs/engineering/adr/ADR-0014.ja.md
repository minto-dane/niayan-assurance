# ADR-0014: 復旧予算を永続化して暴走を防ぐ

状態: 採用方針・独立レビュー待ち。日付: 2026-09-06。対象: recovery-engineering source edition。

## 背景

このシステムは既存ディストリビューションの資産と複数の特権/外部状態を扱うため、単なる関数成功とシステム全体の正常性を混同できません。
この決定は「復旧予算を永続化して暴走を防ぐ」について、故障中の推測を減らし、責任と回復条件を明確にするためのものです。

## 決定

再起動やcontroller交代で予算を戻さず、上限と正常観測を持つ。

## 代替案

無限再起動や単純指数backoffだけでは依存故障を増幅する。

## 影響

予算解除は現在の健康・所有権・認可を要求する。
可用性と安全性の両方への影響をレビューし、停止が必要な範囲と正常に継続できる業務を分けます。
既存の未適格な観測やコールバックを、この決定だけで適格化しません。

## 検証と残る条件

要求との関係はrequirements.jsonが正本です。コード、正/否定試験、障害注入、必要な証明/実機接続を同じsubjectで追跡します。
