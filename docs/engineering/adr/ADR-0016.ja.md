# ADR-0016: 開発証跡をsource subjectへ束縛する

状態: 採用方針・独立レビュー待ち。日付: 2026-09-06。対象: recovery-engineering source edition。

## 背景

このシステムは既存ディストリビューションの資産と複数の特権/外部状態を扱うため、単なる関数成功とシステム全体の正常性を混同できません。
この決定は「開発証跡をsource subjectへ束縛する」について、故障中の推測を減らし、責任と回復条件を明確にするためのものです。

## 決定

実行したcommandと結果とsourceを記録し、参照モデル・Ada・proofを別の層にする。

## 代替案

過去のPASS件数を新しいZIPへ引き継ぐ案は未検証変更を隠す。

## 影響

CI自体は信頼前提。署名/独立レビューなしでproduction approvalを発行しない。
可用性と安全性の両方への影響をレビューし、停止が必要な範囲と正常に継続できる業務を分けます。
既存の未適格な観測やコールバックを、この決定だけで適格化しません。

## 検証と残る条件

要求との関係はrequirements.jsonが正本です。コード、正/否定試験、障害注入、必要な証明/実機接続を同じsubjectで追跡します。
この配布時点でAda実行・GNATprove・実クラスタの検証は未実施です。独立レビュー担当者と承認結果も未登録です。
