# ADR-0022: Intent・receipt・業務受入れの三段階

状態: proposed-for-review。実装方針であり独立レビュー承認は未取得。版: unified-management-2026-09-06。

## 背景

コマンド終了と業務復旧は異なる。応答喪失時の再実行は二重効果を起こす。

## 決定

効果前の永続intent、native台帳のexact receipt、三役署名closureを別にする。Unknownを自動再送しない。

## 代替案

exit=0を成功、timeoutを失敗、TTL後の再発行とする案を拒否する。

## 影響

結果不明時の可用性を犠牲にする場合がある。現場観測と明示recoveryが必要。
