# ADR-0024: 復旧系譜と予約はexact資源集合で管理

状態: proposed-for-review。実装方針であり独立レビュー承認は未取得。版: unified-management-2026-09-06。

## 背景

親の一部だけを復旧して親全体を閉じると、未検査資源の予約が解放される。

## 決定

Recovery_Ofは同一cluster/完全同一(node,resource)集合/新ID/新serial。三役accept後に祖先をResolved_Byで閉じる。

## 代替案

subsetだけの修復で親を成功扱いする案、未確定を消去する案は拒否する。

## 影響

部分的処置でも親の全資源についてread/reconcile/証拠の段階を計画する必要がある。物理停止は別途必須。
