# ADR-0025: 部分tail修復はexact署名と証拠保存後だけ

状態: proposed-for-review。実装方針であり独立レビュー承認は未取得。版: unified-management-2026-09-06。

## 背景

完全record破損と未完appendを同じtruncateで直すと証拠と判断履歴を捨てる。

## 決定

prefix完全検査、head/count/tail/report/policy/期限に三役署名。tail/署名を永続保存後に1..255byte末尾だけ修復。context再利用禁止。

## 代替案

壊れた末尾を無認可で全部削除する案、repairで外部操作も完了扱いにする案を拒否。

## 影響

full record破損・全volumerollbackは別の災害復旧。独立anchor接続は未完。

[controlcoreの試験](../../../../controlcore/docs/verification.ja.md)。
requirements.jsonに対応code/test/hazardを登録。Ada実行・GNATprove・実機故障注入は未実施。
source検査と署名fixtureの成功を実作用や全障害回復の保証としない。
