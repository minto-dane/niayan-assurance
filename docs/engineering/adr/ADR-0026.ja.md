# ADR-0026: 共有契約と管理器実装の二つのprofile

状態: proposed-for-review。実装方針であり独立レビュー承認は未取得。版: unified-management-2026-09-06。

## 背景

共有型を変えずにmanager解釈だけが変わる場合、共有profileだけでは署名した意味を拘束できない。

## 決定

native shared fingerprintとmanager src/runtime/app fingerprintを別々にpolicyへ束縛する。unknown/変更された集合を拒否。

## 代替案

buildごとの自動profile承認、署名の自動更新、互換版を無条件にdecodeする案を拒否。

## 影響

harmlessな実装修正でも再承認が必要。移行・fixture再生成・歴史reader保持を独立手順にする。

## 検証と残る条件

[統合仕様](../specs/unified-management.ja.md)、[機能境界](../specs/capability-matrix.ja.md)、
[controlcoreの試験](../../../../controlcore/docs/verification.ja.md)。
requirements.jsonに対応code/test/hazardを登録。Ada実行・GNATprove・実機故障注入は未実施。
source検査と署名fixtureの成功を実作用や全障害回復の保証としない。
