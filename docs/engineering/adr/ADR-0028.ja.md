# ADR-0028: 第五の設定互換性エンジンと単一writer

状態: proposed-for-review。独立した承認は未取得。

## 背景

四repoの中にnative設定文法を増やし続けると責任が混ざる。

## 決定

configcoreを独立させ、controlcoreを統一入口、pkgcoreを変更ownerのまま維持する。distributionはbuild契約の束である。

## 代替案

全機能を管理CLIへ埋込む案、別設定daemonが無断に書く案を採らない。

## 影響

5repoの固定契約・在庫・試験計画へ追加し、既存gateはopt-inの接続境界を明示する。

## 検証と残る条件

[統合仕様](../specs/suse-config.ja.md)。要求・危険・故障・試験をJSON台帳で対応付ける。
Ada実行/形式証明は未実施。Python工具の試験とsource照合を代替証明にしない。
