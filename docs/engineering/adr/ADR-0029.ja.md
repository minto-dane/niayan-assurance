# ADR-0029: 設定の意味・優先順位・完全性を分離

状態: proposed-for-review。独立した承認は未取得。

## 背景

ファイルが同じでも、新版ではキーの意味や既定値が変わる。

## 決定

Unknown/Absent、三方向merge、native優先順位、exact schema、生成/実行依存を別々に検査する。

## 代替案

ファイルhashだけ、設定の機械的sed、旧版validatorだけの検査を採らない。

## 影響

全native文法は自動生成できず、対象adapterの意味保存検査が必要。

## 検証と残る条件

[統合仕様](../specs/suse-config.ja.md)。要求・危険・故障・試験をJSON台帳で対応付ける。
Ada実行/形式証明は未実施。Python工具の試験とsource照合を代替証明にしない。
