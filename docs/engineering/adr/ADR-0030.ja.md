# ADR-0030: NVIDIAは正確なcapabilityと稼働設定で判定

状態: proposed-for-review。独立した承認は未取得。

## 背景

595の通知経路と旧procfs経路、GPU/driver/kernel/backingの条件は同じではない。

## 決定

exact package/driver/adapterへ能力を束縛し、一通知ownerと必要な保存・署名条件を検査する。

## 代替案

version>=595だから旧hookを消す案、署名検査を解除する案を採らない。

## 影響

電源遷移・容量予約・稼働観測は実機資格化が必要。

## 検証と残る条件

[統合仕様](../specs/suse-config.ja.md)。要求・危険・故障・試験をJSON台帳で対応付ける。
Ada実行/形式証明は未実施。Python工具の試験とsource照合を代替証明にしない。
