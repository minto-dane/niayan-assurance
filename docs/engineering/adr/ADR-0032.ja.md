# ADR-0032: 組立て入力の署名とimage資格化を分離

状態: proposed-for-review。独立した承認は未取得。

## 背景

パッケージ名一覧やテスト成功だけでbootable releaseを名乗ると危険。

## 決定

二者署名、独立source/contract期待値、完全snapshot、RPM-MDとpayloadhashを検査し、KIWI記述生成まで行う。

## 代替案

ライブrepoのlatest追随、gpgcheck無効化、自動root installerを採らない。

## 影響

native RPM署名・依存closure・Secure Boot image・Agama・ライセンス審査は別のrelease gate。

## 検証と残る条件

[統合仕様](../specs/suse-config.ja.md)。要求・危険・故障・試験をJSON台帳で対応付ける。
Ada実行/形式証明は未実施。Python工具の試験とsource照合を代替証明にしない。
