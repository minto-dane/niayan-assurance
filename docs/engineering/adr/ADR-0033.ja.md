# ADR-0033: 設定承認をphase・boot・epochへ束縛する

状態: proposed-for-review。独立した承認は未取得。

## 背景

## 決定

二者署名receiptをexact subject/phase/current floorへ拘束し、元の認可も再確認する。

## 影響
