# ADR-0034: 内容観測は有界かつ非万能とする

状態: proposed-for-review。独立した承認は未取得。

## 背景

一覧漏れ、symlink、巨大ファイル、設定値漏えい、root競合が観測の正しさを損なう。

## 決定

getdents64を有界解析し、属性・内容・xattr・一覧を再照合。未知scopeは拒否し、ログへ値を出さない。

## 代替案

全ディスクを無制限走査、任意include実行、hash比較だけで排他とみなす案を採らない。

## 影響

単一writer、秘密参照の分離、native includeの認証観測、実機I/O検査が必要。

## 検証と残る条件

[統合仕様](../specs/suse-config.ja.md)。要求・危険・故障・試験をJSON台帳で対応付ける。
