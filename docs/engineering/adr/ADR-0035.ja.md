# ADR-0035: 公開Leap 16.0だけを有効ベースにする

状態: proposed-for-review。独立レビュー担当・実行証拠は未確定。
Supersedes: ADR-0031

## 背景
SLES契約を使わず、SLE由来のLeapソースとpublic repositoryを区別する。

## 決定
active profileをleap-16.0に限定し、旧SLESは履歴へ移して入力で拒否する。

## 代替案
SLESとの二重対象、Almaへの変更、署名があれば任意baseを許す方式。

## 影響
署名済みでもbase混在を拒否。Leapの保守周期・公開配布物のlicenseは独立に扱う。

## 検証と残る条件
[統合仕様](../specs/solver-assurance.ja.md)と要求・危険・故障台帳を参照。
source/参照試験はAda実行や証明ではない。適格化までproduction_qualified=false。
