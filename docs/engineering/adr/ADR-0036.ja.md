# ADR-0036: 形式非依存の検査器を第6リポジトリへ分離

状態: proposed-for-review。独立レビュー担当・実行証拠は未確定。
Supersedes: ADR-0028

## 背景
configuration専用repoを保ちつつ、native package semanticsと普遍的な計画検査を分ける。

## 決定
resolvercoreを追加し、neutral AST/claims/ordered actionsを扱う。RPM依存はpkgcore adapterへ閉じる。

## 代替案
pkgcore全体を汎用coreとして使う、RPMのEVRをすべての形式へ強制する方式。

## 影響
6独立build+distribution。DEB/IPS等の実adapterが完成したことにはしない。

## 検証と残る条件
[統合仕様](../specs/solver-assurance.ja.md)と要求・危険・故障台帳を参照。
source/参照試験はAda実行や証明ではない。適格化までproduction_qualified=false。
