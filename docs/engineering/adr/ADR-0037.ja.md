# ADR-0037: ソルバーは非特権の未信頼提案器

状態: proposed-for-review。独立レビュー担当・実行証拠は未確定。
Supersedes: なし

## 背景
依存解決器の結果や複数結果の一致から、ホスト変更の安全性は導けない。

## 決定
libsolvを既定提案器、CaDiCaLを別経路。source・selection・schedule・coverage・native効果・最新認可を独立再検査する。

## 代替案
libsolvのtransactionをそのまま実行、solver多数決だけで承認。

## 影響
solverが誤っても候補を拒否する設計。探索の完全性や最適性は別で、無限再試行をしない。

## 検証と残る条件
[統合仕様](../specs/solver-assurance.ja.md)と要求・危険・故障台帳を参照。
