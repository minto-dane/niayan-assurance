# ADR-0038: SATモデル検査とUNSAT証明検査を分離

状態: proposed-for-review。独立レビュー担当・実行証拠は未確定。
Supersedes: なし

## 背景
正しいSAT式でもRPMからの投影が違えば、元の要求を検証したことにならない。

## 決定
SATは元Universeへ直接評価。UNSATは同Uから再生成したBoolean緩和に対する独立RUP/RAT検査。

## 代替案
外部CNFを信頼、UNSAT終了値だけ採用、SATでもproof-hintを権威にする方式。

## 影響
no-candidate/timeout/unsupportedはUNSATではない。予算/順序はCNF外なのでSATでは追加検査を要する。
