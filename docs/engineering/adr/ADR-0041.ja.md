# ADR-0041: 長い検査後の生きた認可を再照合

状態: proposed-for-review。独立レビュー担当・実行証拠は未確定。
Supersedes: なし

## 背景
検査中にboot/trust/config/排他予約が変わると、以前のvalid候補を適用できない。

## 決定
exact physical plan・binding・coverage検査後、Recheck_Currentと元Authorizeを再実行する。

## 代替案
開始時だけ検査、キャッシュされた正常報告を再利用、旧正解で復旧まで許可。

## 影響
実観測・排他・署名源は必須callback。SDKを全workerに接続済みとは宣言しない。

[統合仕様](../specs/solver-assurance.ja.md)と要求・危険・故障台帳を参照。
