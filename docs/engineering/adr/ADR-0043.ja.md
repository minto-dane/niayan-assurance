# ADR-0043: Niaカタログ単独所有と新規導入

状態: proposed-for-review。独立レビュー・本番資格は未完。2026-09-07。

## 背景
既存OSの移行と新規ディストリビューション組立てを混同していた。

## 決定
APT/dpkg/RPM/Zypperのホスト管理DBを引き継ぐ義務を廃止する。新規NiaルートとNiaカタログだけが正本。上流ABI・配置・実行時契約は別に検査する。

## 代替案
複数DBを同時更新する互換層、既存OSへのin-place変換。いずれも製品の初期対象にしない。

## 影響
全root実行器とカタログWALの実接続はなお必要。既存guardを外すだけでは実装完了でない。
