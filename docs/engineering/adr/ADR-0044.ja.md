# ADR-0044: DEB意味層と非特権取り込み

状態: proposed-for-review。独立レビュー・本番資格は未完。2026-09-07。

## 背景
RPMバージョン比較やscriptletモデルをDEBへ流用すると意味が変わる。

## 決定
署名InReleaseからPackages/DEBおよびSourcesへ照合し、非実行のインベントリを作る。native DEB比較をSPARKに分離し、共通resolverへRPM/DEB固有意味を混入させない。

## 代替案
dpkgのインストール結果をそのまま信頼する、ソルバーの解析結果だけを採用する。

## 影響
限定parserと最終集合検査は実装したが、全効果とunpack/configure phaseの独立検査器は未接続。未対応入力は拒否する。

## 検証と残る条件
仕様: [distribution/docs/ownership-and-effects.ja.md](../../../../distribution/docs/ownership-and-effects.ja.md)。Python工具の検査はAda実行/形式証明ではない。
