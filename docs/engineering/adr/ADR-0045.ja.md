# ADR-0045: 回復ドメイン・暗号化・署名起動

状態: superseded。ADR-0048により置換。2026-09-07。

## 背景
OS復旧で正当なデータ、秘密鍵失効、監査、既知の制御世代を戻してはいけない。

## 決定
LUKS2/Btrfs可変rootとroot内Nia catalogを同一世代へ結び付ける。control/trust/CAS/secrets/log/dataを別のrollback domainへ置く。署名UKIと独立rescueを使う。

## 代替案
全ディスクを一括snapshot、OS更新ごと全データrollback、Secure Boot無効化で初期導入。

## 影響
構造validatorと設計を追加した。partition/鍵登録/boot image書込/電源断復元は未実施であり具体installerが必要。
