# ADR-0046: 再現性を正確な配布成果物へ拘束

状態: proposed-for-review。独立レビュー・本番資格は未完。2026-09-07。

## 背景
再現可能というパッケージ名の評判やSBOMは当該DEBの同一性証明ではない。

## 決定
原本DEB、認証したsource manifest、buildinfo、配布Release、policyを独立rebuilder receiptsへ結び付ける。ダッシュボードのunsigned成功を署名証拠へ変換しない。

## 代替案
同じsourceから二回buildしただけで配布binaryまで同一と扱う、署名をsource安全性証明と扱う。

## 影響
実際のissuer/鍵ライフサイクル/完全な公開buildinfo取得は未接続。合成証拠の試験は本番資格でない。
