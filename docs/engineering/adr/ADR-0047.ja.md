# ADR-0047: 製品仕様と継承部品契約の階層

状態: proposed-for-review。独立レビュー・本番資格は未完。2026-09-07。

## 背景
過去のSUSE/Fedora記述と新製品構成を一つの規範として読むと矛盾する。

## 決定
製品identity/profileとdistribution/docsをNiaの構成正本とする。component安全条件は弱めず、旧製品前提だけを明示的に置換する。history/evidenceは現行資格に流用しない。

## 代替案
全履歴の削除、暗黙な一括rename、古いPASSを現行版へ流用。

## 影響
MC_*や暗号domainは互換安全性のため残す。niaコマンドを入口とし既存missionctlは内部互換名。RPM recipeはinactive。

## 検証と残る条件
仕様: [distribution/docs/architecture.ja.md](../../../../distribution/docs/architecture.ja.md)。Python工具の検査はAda実行/形式証明ではない。
