# ADR-0050 独立anchorで認証されたcohort復旧

状態: proposed-for-review。独立した承認は未実施。

## 背景
コア・カタログ・historyの同時欠損時に、同じ破損領域を信頼して新しい正常状態を作ることはできない。

## 決定
完全な原本集合、外部の正確な受入anchor、現在のtrust floor、独立したrecovery/witness署名を要求する。chunk複製から別candidateを構築し、native状態と外部効果を照合してからOperationalへ戻す。

## 代替案
localコピーの多数決、mtime順の最新採用、空journal再初期化、復旧のための署名無効化は採用しない。root snapshotだけではtrust・history・業務データの別責任を扱えない。

## 影響
anchor発行・独立保管と監査が必要。全原本又は全鍵の喪失を自動で解決しない。Python工具は非特権の再構成までで、live publishの権威は持たない。

## 検証と残る条件
署名・旧世代・属性・複製破損・証拠I/O・中断のPython試験。SPARK状態機械はAda実行と証明、独立rescueとnative validatorの統合試験が未完。
