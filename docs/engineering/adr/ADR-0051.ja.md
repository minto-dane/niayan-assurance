# ADR-0051 CapsuleをNiaの第一級配備モデルにする

状態: proposed-for-review。独立した承認は未実施。

## 背景
アプリ隔離、世代の更新、委任ソフトウェア管理を、第二のinstalled-state管理器なしで表現する必要がある。

## 決定
capsulecoreを独立した7番目のコードベースにする。Nia catalogが正本。Confined/Isolatedを能力契約で扱い、Nativeは別のhost配備経路。Flatpakは要求とartifactの入力だけに限定する。

## 代替案
host HOMEやbusを丸ごとbindする簡易sandbox、失敗時のNative fallback、Flatpak導入DBの共同管理、実行時OverlayFS合成を基準とする方法は採用しない。

## 影響
broker本人確認、LSM/seccomp、VMM、GPU/ABIの実接続が必要。private dataと世代を分離する。既存APIの暗号domainを名前変更だけで壊さない。

## 検証と残る条件
能力交差・否定条件、materialized tree、Flatpak未対応入力、wireを試験する。実sandbox/portal/GPU/VMは未実施。型付き判断とkernel enforcementの違いを文書化する。
