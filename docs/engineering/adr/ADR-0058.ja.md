# ADR-0058 原本DEBから再検査する媒体索引

状態: proposed-for-review。独立承認と製品受入は未実施。

## 背景

inutocと媒体一覧の公開構文は存在するが、実処理は未接続だった。
媒体の可変キャッシュを導入済みDBや供給認証の代わりにすると、元DEBと異なる情報で
更新候補を選ぶおそれがある。原本の保持と独立した管理主体を維持して実装する必要がある。

## 決定

inutocによる決定的な`.toc`の作成と、installp/geninstallの媒体一覧を
同じ[媒体処理](../../../../distribution/native/media.ja.md)へ接続する。
元DEB読取器を使い、一覧時も原本を再検査する。既存索引と内容が違う場合は拒否する。
元DEB、package/version/architecture、効果hashを保持し、未知形式の索引を上書きしない。
保持したdirectory fd、flock、通常ファイル・前後属性確認、一時ファイルのfsync/renameを使う。

## 代替案

dpkgやAPTへの委譲、索引だけを信用する一覧、原本の書換え、部分的な索引の直接上書きは採用しない。
別の導入済みDBは作らず、索引は未認証の媒体キャッシュとする。

## 影響

公開3コマンドの媒体操作が動作する。ローカル媒体であり稼働更新器とは接続しない。
英語と既存7catalogへ媒体の案内・診断を追加する。機械処理用の列と識別子は翻訳しない。
DEBのepoch等を失わないpercent encodingを明示し、参照した応答形式の完全な互換性は主張しない。
Ada/SPARK、固定vendor、署名形式と導入済み状態には変更を加えない。

## 検証と残る条件

実公開コマンド、原本不変、独立ディレクトリでの再現性、同一索引の再利用、古い索引、
入力範囲、読取中の媒体変更、書込み・同期・renameの失敗を試験する。
保存済みの実DEBについても過去のhashと照合して実行する。
模擬IO失敗を実電源断の証跡にしない。供給認証、稼働catalogとtransaction、完全な応答互換性、
媒体整理時の参照保持、全DEB意味と完全置換ISOは未完である。
