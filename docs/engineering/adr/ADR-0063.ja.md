# ADR-0063 binary関係項目のnative読取

状態: proposed-for-review。独立承認と製品受入は未実施。

## 背景

## 決定

原本制御項目と識別情報に続き、[binary関係項目](../../../../distribution/native/deb-relations.ja.md)をnativeで解釈する。
項目種別・順序・group・版条件・architecture labelをprivateな有界式へ保持する。
Providesの版は等号のみ、ソース保持項目は無修飾名と厳密版を必要とする。
元DEB観測SDKで採用11項目の構文を検査し、未知任意項目の原本保持は継続する。

## 代替案

外部管理器への本番委譲、選択肢の平坦化、foreign labelのamd64への変換、
Replacesを上書き許可へ変える実装は採用しない。
## 影響

fixed vendorと既存数理型を改変せず、個々のatomを読める内部APIを提供する。
native側はProvidesのarchitecture指定も保持する。既存offline参照の限定profileは
独立比較できる範囲だけのoracleとして使用し、全面互換を主張しない。

## 検証と残る条件

11項目の規則、演算子・選択肢・資源境界、原本一致と不在項目、実原本経路を検査する。
新runtimeはSPARK対象外。構文の成功だけでは、満たされる依存・競合、
Multi-Archの共存条件、phaseの順序、ソース保持の履行、実行権限を認めない。
これらは稼働catalog・計画・原本認証・効果処理とともに続ける。
