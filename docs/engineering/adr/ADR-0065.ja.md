# ADR-0065 原本tarの有界観測と属性保持

状態: proposed-for-review。独立承認と製品受入は未実施。

## 背景

data streamの保存だけではファイル内容・リンク・権限・所有権を判定できない。
既存の世代v1形式へhardlinkや特殊permissionを削って渡すと、原本の意味を失う。

## 決定

[元DEB payload SDK](../../../../distribution/native/deb-payload.ja.md)を追加し、
独立framingと未改変libarchiveを照合する。通常ファイル内容・symlink文字列・
属性blobを既存CASに保持し、全体成功後だけprivate inventoryを返す。
byte名と表示localeを分離し、thread-local localeを復元する。
全hardlink graphを解決し、原本tarも保持する。新たな導入済みDBは作らない。

## 上流との境界

ライブラリが無視する拡張を成功としない。global PAX、sparse、NFS4 ACLなど未対応profileは
明示的に拒否する。採用POSIX ACLの構文を事前検査し、負のPAX小数時刻を正確に保持する。
これらはNia側の形式境界であり、上流ソースへ独自patchを加えない。

## 代替案

任意tarの特権展開、未知属性の黙認、全payloadのメモリ確保、旧世代形式へ属性を削って
適合させる方法は採用しない。上流のglobal locale変更もSDK内では行わない。

## 影響

原本tarと個別contentを保持する追加CAS容量が必要である。

## 検証と残る条件

合成DEBと保存済み原本、独立tar/CAS oracle、root拒否、locale復元、全コンパイル・
試験と二ビルド再現性を検査する。SPARK proof入力は変更せず、新runtimeを証明済みとしない。
全DEB効果、世代形式・実行器の拡張、catalog・認可・実bootと完全置換ISOは別の未完工程である。
