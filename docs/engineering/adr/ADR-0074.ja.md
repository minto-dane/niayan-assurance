# ADR-0074 版付き世代へのnative保持閉包の束縛

状態: proposed-for-review。隔離世代SDKへの接続。本番起動・全世代GCは未認定。

## 背景

catalog由来の正確な保持一覧を保存しても、受理する世代へhashが束縛されていなければ
公開時や現世代の観測時に一覧の欠落を検出できない。

## 決定

[世代保持仕様](../../../../distribution/native/generation-retention.ja.md)に従いNIAGEN02を追加する。
旧形式の予約byteとtransaction導出は維持する。新形式は保持hashを必須とし、既存manifest pin
から参照する。native公開・観測では旧形式を拒否し、catalog再構築より先に全掲載objectを検査する。
StageとPublishの内部APIに有限期限を必須で追加し、認可callbackの前後にも検査する。

## 代替案

旧形式の予約領域の無断転用、別の保持DB、同じpin identityの別対象への上書きは採用しない。
構造検査SDKと記録観測は旧形式を引き続き扱う。旧形式の既存要求を新版へ暗黙変換しない。

## 影響

descriptor・root.state・ファイルプランの形式、共有contract、数学的proof入力は変更しない。
nativeの全属性を既存ファイルプランへ切り捨てる変更も行わない。

## 検証と残る条件

版別codec/vector、旧形式公開拒否、各受入境界での全member欠落、期限と認可中の期限切れを
既存の復旧行列へ追加する。独立readerで世代pinから元DEBまでの参照と故障試験集合を照合する。
期限検査の追加で不正hash拒否時のstatusを上書きする回帰を既存試験が検出し、明示的なDeniedを保つ。
全履歴/効果/認証/復旧root、GC、本番の同一予約admission、全DEB実行、実bootは未完である。
