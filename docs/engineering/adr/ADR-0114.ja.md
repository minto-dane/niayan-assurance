# ADR-0114: 初回bank準備のroot supervisor session

## 背景

専用bankの初期化とRO観測だけでは、準備中のRW化、実worker終了、RO再検査と予約保持を一つの管理寿命へ
結べない。一つのfilesystemにある完成済み世代を後の準備で再びRWにすると既存観測を壊す。

## 決定

内部root supervisor用のseqpacket sessionを追加する。kernelの接続元/各messageのUID0と同じPIDを要求し、
SO_PEERPIDFDでtaskを保持する。要求は既存request、独立worker/device plan/boot/bank identityと実CAS/archive FDへ束縛する。
root管理面の認証と、利用者同意・供給/世代admissionは区別する。後者はsupervisorが独立に完了させる責務で未接続である。

空のRO bankに限りBank/device予約を取得し、永続O_EXCL attemptの同期後にRWへ変更する。
既存Bankへ検査済みの継承lock OFDを渡す内部APIを追加し、setprivで7 capabilityへ縮小した別childが元prepare/verifyを呼ぶ。
controllerのmount/setpcap権限をtar parserへ渡さず、上流codeや既存ELF workerの検査を変更しない。
RO移行と全再検査後にFrozenRootを保持し、受信CAS/archiveコピーを閉じてからreadinessを返す。
新しいCAS予約を添えたobserveでもBank/device/rootは保持する。元期限を延長しない。

close/切断/期限切れではROを確認して自身の予約を解放する。永続attemptは削除せず、終了記録を公開/boot許可にしない。
systemdはcontroller cgroup全体を停止し、stop hookで元deviceを再確認してROへ戻す。
同じcgroupのExecStopPostまでSIGKILLに巻き込まれる場合に備え、OnFailureが別cgroupのseal serviceを起動する。
RO化に失敗した場合は未完のまま残し、実行要求の再送・RW復帰・成功記録の生成は行わない。
初回使用record後は旧準備serviceの再起動を拒否する。既存/使用済みbankのRW再利用は一切提供しない。

## 代替案

準備serviceへmount権限を追加する方法、全archive解析をcontroller内で行う方法、受信CAS OFDを返却後も
保持してnativeの次の予約を妨げる方法、bindingを応答から作る方法、失敗後のrecord削除/自動再送は採用しない。
署名や同意の代わりに常時成功callbackを置かない。root RPCが一般利用者の認可判断を完了したとはしない。

## 影響

controllerはhost mount namespaceを扱い、元workerに必要なcapabilityに加えてSYS_ADMIN/SETPCAPを持つ。
namespaceを作るProtectSystem等は使わず、資源/通信/新規namespace/dumpを制限する。完全sandboxではない。
root管理面・特権mount/raw device writerは信頼境界内である。全寿命のsite認可取消や外部writerの遮断は別途必要。
電断でfinally/stop hookは実行されず、kernel I/Oの厳密な時間上限も未保証である。

## 検証と残る条件

実DEB、実bootstrap済みの使い捨てGPT/ext4 bank、実worker、実UID/FDでprepare-freeze/observe/closeを検査する。
誤worker/mount/plan/FD、非root接続を拒否し、readiness後の新CAS OFD取得とBank保持を確認する。
切断、期限切れ、保持中の特権RW drift後のSIGKILL/stop hookを独立VMで検査する。
元tree/記録の不変、使用済みbank拒否と通常caseの再起動後RO/旧writer拒否も確認する。
初回のprepare/inspectの追加field比較不備を修正し、失敗ログと実extracted結果を保存する。
強制終了試験でExecStopPostまでSIGKILLされた失敗を保存し、独立OnFailure serviceで再検査する。

本番の認可/供給/同意providerとnative SDK adapter、bank slot管理・GC、実root/boot切替・復旧、全DEB効果、
完全置換ISOと全言語翻訳は未完。人工scopeでの成功を本番admissionや実稼働世代への接続とはしない。
