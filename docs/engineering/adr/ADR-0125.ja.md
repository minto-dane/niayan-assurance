# ADR-0125: native管理者認証の非同期監視

状態: proposed-for-review。REQ-162 / HAZ-149 / FAULT-162。

## 背景

Pkg_Operator_Authorizationは実polkit、実accepted peer/pidfd、独立plan/requestと元期限を扱う。
ただしnativeのD-Bus呼出しは同期であり、root supervisorが直接待つと別のworker/controllerの
取消監視まで止まり得る。polkitのtrueを全managed guardの成功へ変換する解決は採用しない。

## 決定

既存C/SDKは変更せず、内部pkg_operator_guardを専用root子processとして配布する。
root-preparation 0.11.0のOperatorGuardは固定した保護ELFをFDでpinして起動し、
private pipeで一件ずつ順序付きの再確認を要求する。stdin/stdoutは非blocking、stderrは破棄する。
子は最大1200確認/12000 loop、親は元BOOTTIME期限（最大120秒）を保持する。
親の新規認証待ちはその元期限、以後の各再確認待ちは最大1000 msに制限する。
親のAPIは非blockingであり、callerが全監視FDと期限を同じevent loopで処理しなければならない。

子は実accepted peerをnative SDKへ渡し、Checkの前後に独立CLOCK_BOOTTIMEを採取する。
応答はNIAOPR01、sequence、開始/終了msの32 byteで、要求は期待sequenceの8 byte。
親は番号、要求開始時刻との順序、現在時刻/期限と終了後最大1000 msの鮮度を照合する。
初回の長い対話待ちでも、pipe内に滞留した古い成功を新しい観測にしてはならない。
応答はこのprivate childからの一時的観測であり、署名ticket、保存可能grant、世代認可ではない。

親は実peer socketとSO_PEERPIDFD、helperのpidfdも監視する。取消/切断/終了、失効、
無応答、番号/形式/時刻不一致はFAILEDに移し、以後の再確認/受信を拒否する。
既存requestと計画同意の応答を認証して消費した後にのみ開始する。未読packetを認証や同意に
推測変換しない。受信FD/UID/planの主張だけでこの前提を満たしたとはしない。

Closeは状態と所有参照を取り外し、未回収の実子leaderを保持したまま専用groupへSIGKILLし、
最大5秒の回収を行う。残りのFD/pipeも解放を試み、失敗は不確定として報告する。
forkしたコピーから元の子をkill/reapしない。単一owner、外部reaperなしという契約を保つ。
FAILEDになっても物理効果が撤回されたとは扱わず、callerはcontroller/workerの遮断と
必須のCloseを行う。scope全体の所有者がこれらの寿命を監督する。

## 代替案

D-Bus待ちをrootの効果監視loopで直接行わず、認証Cへ別の非同期実装も複製しない。
継続的な無条件heartbeat、再認証の自動更新、初回trueの永続cacheも使わない。
公開代替コマンド、setuid入口、独自password DBや既定allow ruleは追加しない。

## 影響

認可結果は現在の点観測に限る。次の効果の直前にも新しいnative確認と供給/同意/世代guardが必要。
polkit Changedを伴わない外部rule条件、侵害された基盤、kernel非応答、画面消失、全writer排他は
この子processだけでは保証しない。返答受信後の取消を物理遮断へつなぐsupervisorは未完である。
既存SDKのroot/nonroot境界を解除せず、本番の正確な計画同意やnative実行器も代替しない。

## 検証と残る条件

実Ada mainのコンパイル、親側strict typing、実制御関数に対する深さ省略なしの有限履歴探索、
FD解放時の番号再利用と非root起動拒否を検査する。モデルは全Python/OS/FFIの証明ではない。
専用VMの実DEB/実polkitでは、既定拒否、正確なfixture context、ルール変更、authority再起動、
peer取消/終了、helperのSIGSTOP、古い初回返答、番号/重複要求と所有資源の終了を検査する。
試験の狭いfixture ruleは最後に削除する。本番認証dialog/計画同意/物理効果の受入ではない。

新規のAda特権main、Python/FFIと全runtimeの形式保証・規格適合は未完として保持する。
Cを別言語へ書き換えて保証条件を緩めたものではなく、既存Cに変更はない。
不変C/SPARKの全証明や全体suiteを反復せず、source-bound artifactと残件を記録する。
