# ADR-0126: Ada世代実行とroot監視・Debian配布の統合

状態: proposed-for-review。REQ-163 / HAZ-150 / FAULT-163。

## 決定

小さなSDKの個別受入を繰り返す工程から、まとまった実装とリリース前検証へ移行する。
Ada Pkg_Generation_Executionで既存Stageの初期化/全batch/準備/再検査/保持を結合する。
新しい永続形式、認可の既定成功、rootでの非特権SDK実行、公開代替コマンドは追加しない。
現在の認可/設定/物理観測/lifetime providerは必須で、元期限/一owner/一試行を固定する。
開始済み変更の失敗を未実行へ変換せず、既存のattempt/CAS/記録を保持する。

root側Supervisorは非blocking controller clientとOperatorGuardを同じloopで扱う。
独立FDと記録で応答を検査し、取消時はobserver後片付けより先にcontrollerを切断する。
controller EOF、物理RO、catalog公開、実boot成功は異なる観測として扱う。

Debian recipeへroot-preparationとarchive-observerを正式な独自DEBとして含め、
全source hashと対応ソースを保持する。起動/storage/trust配備は明示的な接続まで行わない。
開発ビルドは標準nocheck、手動の出荷前配布CIは--releaseで試験を実行する。
モードを記録し、未検証ビルドを受入済みとして扱わない。

## 残る条件

本番provider/launcher、全DEB効果、全writer排他、catalog/boot切替、復旧と完全置換ISOは未完。
Adaはコンパイル済みで、実インスタンスの全経路と形式保証は未認定。
rootの通常fixture統合は成功、取消の実停止/RO/記録保持は観測したがharness全体は失敗した。
source-bound記録と修正を残し、利用者の指示により再試験はリリース前へ延期する。
