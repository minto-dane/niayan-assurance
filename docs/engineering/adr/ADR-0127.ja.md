# ADR-0127: 採用要求と正確な計画同意

状態: proposed-for-review。REQ-164 / HAZ-151 / FAULT-164。

採用コマンドの副作用なしgrammarを共有し、root側で元の要求を独立に解析する。
同意対象はnative plan/generation/request/boot/元期限とsealed表示FDのhashへ束縛する。
同意接続と管理者認証接続を同一にし、root効果中も元peer/pidfdと期限を確認する。
準備ACKを取引確定と呼ばず、送信後の通信失敗は結果不明で自動再送しない。

[実装仕様](../../../../distribution/native/plan-consent.ja.md)に形式と責務を示す。
純粋Ada codec、client/receiver、Supervisorの必須同意は追加したが本番planner/launcher、
供給/世代認可と実終端確定は未接続。コンパイル/型/翻訳asset生成のみで、出荷認定ではない。
