# ADR-0128: 明示的な世代切替、検証起動と脅威報告の意味

状態: proposed-for-review。REQ-165 / HAZ-152 / FAULT-165。

自動Trial・健康失敗による自動旧版復帰を標準にしない。待機側の準備、データ互換性と
独立rescue、明示的な一回の切替、切替後の健康確認、別の確定認可を分ける。
回復操作も現在の方針とデータを用いた新しい認可済みトランザクションとする。

署名された旧版や同じsecurity versionにも未知の脆弱性があり得る。既知の禁止下限と
非rollback anchorは後退防止の条件であって脆弱性不在の証明ではない。CVE/勧告の不在を
無修正/安全の根拠にせず、保守対象stable修正とDebian backport対応のfreshな観測を必要とする。
機関の実環境悪用確認報告は、実端末の侵害とは別のsource/record/date付き情報として扱う。

Microsoft署名shimを維持し、インストーラーから導入後・更新・復旧までSecure Bootを
無効化せず使う。kernelだけでなくinitrd/cmdline/OS内容/設定/モジュールまで使用前検証する。
NVIDIAのMOKはmodule-only証明書とし、boot用鍵と分離する。登録/実信頼/署名/ロードまでの
確認が終わるまでpendingとし、暗号化保存だけで署名oracleを保護したとはしない。

[起動/署名の条件](../../../../distribution/boot/README.ja.md)と
[脅威報告](../../../../distribution/native/threat-reporting.ja.md)に詳細を示す。
現段階は純粋Ada判断モデルとオフラインMOK鍵準備工具で、実anchor/boot/署名配布/
NVIDIA/signing providerは未接続。意味の変更に必要な既存試験の追随のみとし、
試験コードの量産と反復試験を止める。挙動試験/形式保証/徹底レビューはリリース前CIへ集約する。
