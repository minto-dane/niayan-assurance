# ADR-0129: 計画時の供給入力に固定した継続観測

状態: proposed-for-review。REQ-166 / HAZ-153 / FAULT-166。

計画時にnative readerが認証したpolicy/floor hashとUTCを保持し、元の世代/transaction/
plan/map/retained policy/BOOTTIME期限と一緒に、専用非root observerへ渡す。
保持中のroot効果を監督するloopでoperatorと並行して現在性を観測し、各効果境界では
既に進行中の要求とは別の新しい両観測とnative Admissionを必要とする。
設定変更・読取拒否・時計後退・子停止・期限切れを既定成功や新しい設定の採用で回避しない。

専用identityはwriter/signing accountと分け、store/bank/peer FDを継承しない。
native観測はCAS予約を取得せず、保持中workerとの再予約による待ち合わせを避ける。
固定ELF/順序付きprivate pipe/child pidfd/有限応答/元期限で結び、取消時はeffect controllerを
先に切断してからobserverを回収する。既存の実効果と復旧記録の意味は変更しない。

観測の成功を実行や世代公開の認可にはしない。必須Admissionにも完全な供給Bindingを渡し、
計画器が保持する文脈と照合する。元のnative publisherのmanaged gateと供給callbackを維持する。
点観測間の瞬時失効、OSの最大停止時間、独立floor anchorはこの実装の保証ではない。
詳細は[継続供給観測](../../../../distribution/native/supply-guard.ja.md)。

利用者の最新指示に従い、コンパイル/型検査を含む検証はリリース前へ集約する。
新しい試験コードは追加しない。実planner/世代認可/launcherは未接続であり、既存root統合試験も
新しい必須Bindingと実observerへ追随させて出荷前に実行する必要がある。現行の受入成功を示さない。
