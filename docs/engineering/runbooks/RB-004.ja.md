# RB-004: サービス復旧の連続失敗

## 開始条件・封じ込め

再起動責任者を確認し、systemd/クラスタ/独自管理器の競合を止める。予算記録を削除しない。

## 読み取りと証拠

boot/invocation、依存先、設定、データ所有権、時間窓と累積予算、最後のintent/resultを確認する。
対象ID、plan、世代、boot、時刻の種別、ログ位置、原本のdigest、実行者と認可を記録します。秘密payloadを一般ログへ貼り付けません。

## 認可された処置

結果不明のcommandは再送せず再観測する。必要な依存修復後、認可された回数だけ復旧し、新しい正常観測と安定時間を要求する。
実施前に、破壊的操作の対象範囲と回復経路を別の担当者が確認します。未接続のSDKを本番コマンドと取り違えません。

## 終了条件・禁止事項

command exit0だけでは解除しない。上限に到達したら隔離/別ノード移行を適格なクラスタ管理者へ委譲する。
復旧後は新規変更を段階的に再開し、再発監視と障害報告を残します。失敗した証拠は成功ログで上書きしません。
