# RB-008: TLS・署名鍵・時刻の異常

## 開始条件・封じ込め

新しい変更認可を停止し、既存正常業務と管理系の影響を分離する。時刻/bootの変化を保存する。

## 読み取りと証拠

証明書チェーン、期限、失効、信頼世代、clock uncertainty、要求scopeを確認する。署名の成功と観測の真実は別に検査する。
対象ID、plan、世代、boot、時刻の種別、ログ位置、原本のdigest、実行者と認可を記録します。秘密payloadを一般ログへ貼り付けません。

## 認可された処置

保護された管理経路で認証情報を更新し、独立承認と正確なprofileで再参加する。失効情報をOS snapshotから戻さない。
実施前に、破壊的操作の対象範囲と回復経路を別の担当者が確認します。未接続のSDKを本番コマンドと取り違えません。

## 終了条件・禁止事項

TLS検査・監査・Secure Boot・SELinuxを解除して復旧扱いにする手順は禁止。
復旧後は新規変更を段階的に再開し、再発監視と障害報告を残します。失敗した証拠は成功ログで上書きしません。
