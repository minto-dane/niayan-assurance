# stop-v1 人工適合試験ベクトル
実クラスタから取得した証拠ではありません。固定の試験用識別子と公開テスト鍵の署名です。本番で信頼しないでください。
policy.bin は同一資源を三つの別ノードで使用する集合。署名要求者と隔離観測者の鍵は別です。
sealed-state.bin はローカル時計200で使用条件を満たし、1000では期限切れです。
node-*.bin、fence-1.bin は対応する署名との照合に使います。
wrong-domain.sig、wrong-role.sig、再ハッシュした予約領域/真偽値異常を拒否してください。
old-guard-evidence.bin は署名自体は正しいが、ポリシーと異なるguard revisionであり、状態遷移で拒否するものです。
CLIで署名が正しいと出ても、方針の権威、全対象の網羅、物理的停止、鮮度、実行許可の検証にはなりません。
